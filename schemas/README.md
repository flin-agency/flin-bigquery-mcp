# MCPB manifest schema

`mcpb-manifest-v0.4.schema.json` is copied unchanged from the official `@anthropic-ai/mcpb` npm package, version 2.1.2 (MIT; see `LICENSE.mcpb`). Source project: https://github.com/modelcontextprotocol/mcpb. It is used only at build time to validate the extension manifest.

The Python builder writes the standard MCPB ZIP format directly. No Node/npm tooling is required or included in the distribution.
